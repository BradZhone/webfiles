# 知识库格式规范

本文档定义了 WebFiles 知识库中 Markdown 文件的标准格式，遵循此规范可确保最佳的渲染效果和功能支持。

---

## 1. Frontmatter（YAML 元数据）

每个文档**必须**以 YAML frontmatter 开头：

```yaml
---
title: 文档标题           # 必填 — 用于图谱节点标签和搜索
tags:                     # 推荐 — 用于分类和图谱连接
  - 标签1
  - 标签2
type: note               # 可选 — note | article | todo | annotation
created: 2026-05-08      # 推荐 — 格式 YYYY-MM-DD
aliases:                 # 可选 — 文档别名，用于 wikilink 匹配
  - 别名1
---
```

### 字段说明

| 字段 | 必要性 | 格式 | 说明 |
|------|--------|------|------|
| title | **必填** | 字符串 | 文档标题，显示在图谱和搜索结果中 |
| tags | 推荐 | 字符串数组 | 标签，用于分类筛选和图谱标签连接 |
| created | 推荐 | YYYY-MM-DD | 创建日期 |
| type | 可选 | 枚举 | note / article / todo / annotation |
| aliases | 可选 | 字符串数组 | 别名，支持多种 wikilink 引用 |

## 2. 正文语法

### 2.1 支持的 Markdown 语法

| 语法 | 示例 | 支持状态 |
|------|------|---------|
| 标题 | `# H1` ~ `###### H6` | ✅ 完整支持 |
| 粗体 | `**粗体**` | ✅ |
| 斜体 | `*斜体*` | ✅ |
| 删除线 | `~~删除~~` | ✅ |
| 链接 | `[文本](url)` | ✅ |
| 图片 | `![alt](url)` | ✅ |
| 代码块 | ````lang ... ``` | ✅ 带语法高亮 |
| 行内代码 | `` `code` `` | ✅ |
| 引用 | `> 引用` | ✅ |
| 有序列表 | `1. 项目` | ✅ |
| 无序列表 | `- 项目` | ✅ |
| 任务列表 | `- [ ] / - [x]` | ✅ 可交互勾选 |
| 表格 | `| a | b |` | ✅ |
| 水平线 | `---` | ✅ |
| Wikilinks | `[[文件名]]` | ✅ 知识库内跳转 |
| Mermaid | ````mermaid ... ``` | ✅ 图表渲染 |

### 2.2 Wikilinks

知识库内文档互相引用使用双方括号语法：

- 基本引用：`[[文档名]]`
- 带显示文本：`[[文档名|显示文本]]`
- 引用规则：文档名为不含 `.md` 后缀的文件 basename

### 2.3 不支持的语法

| 语法 | 说明 |
|------|------|
| LaTeX 公式 | `$...$` / `$$...$$` 不渲染 |
| Obsidian Callout | `> [!note]` 仅显示为普通引用 |
| 文件嵌入 | `![[file]]` 不支持 |
| 脚注 | `[^1]` 不支持 |

## 3. 文件组织

### 3.1 目录结构

- 文件名使用中文或英文，避免特殊字符（`< > : " / \ | ? *`）
- 子文件夹自由组织，图谱按目录自动聚类着色
- `_notes/` 目录为系统批注存储，自动隐藏

### 3.2 推荐命名

- 日期前缀：`2026-05-08-会议记录.md`
- 简洁描述：`项目规划.md`
- 避免过长文件名（建议 < 50 字符）

---

## 4. 格式检查规则

| 级别 | 规则 | 自动修复 |
|------|------|---------|
| 🔴 错误 | 缺少 frontmatter | ✅ 自动生成 |
| 🔴 错误 | frontmatter 语法错误 | ⚠️ 尝试修复 |
| 🟡 警告 | 缺少 title 字段 | ✅ 从 H1 提取 |
| 🟡 警告 | 缺少 tags 字段 | ✅ 从正文 #tag 提取 |
| 🟡 警告 | 缺少 created 日期 | ✅ 从文件时间填充 |
| 🟡 警告 | 正文残留编辑标记 | ✅ 自动清除 |
| 🟢 提示 | 标题层级跳跃 | 仅提示 |
| 🟢 提示 | 孤立 wikilink（目标不存在） | 仅提示 |
